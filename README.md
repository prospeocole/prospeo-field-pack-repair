# Prospeo Pack Repair

Reference materials for the partner pack repair Project on claude.ai.
Do not edit anything here. If a gold pack changes, replace the file (same name) and tell the team.

All files sit flat, the name says what each one is:
- repair_v2.py and repair_png.py: the repair engine
- individual-gold-*: approved references for individual field packs (Chris Ritson v2, gold code CHRISR50)
- group-gold-*: approved references for group packs (Jed Mahrle 300 leads, gold code JEDM50)
